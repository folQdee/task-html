# HTML: базовая разметка

Учебная задача по семантической HTML-разметке: заголовки и нумерованный список ссылок.

**Решение:** [src/index.html](src/index.html): `h1`, `h2` и список `ol` со ссылками на справочники по HTML.

Стек: HTML, тесты Jest.

## Условие задачи

В файле `src/index.html` внутри `<body>` сделайте страницу следующего вида:

-   Заголовок первого уровня
-   Заголовок второго уровня
-   Нумерованный список из трёх элементов, каждый из которых ссылка на какой-то ресурс

## Запуск

```
npm install
npm run test
```
